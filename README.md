# Bhavya Modi — Professional Engineering & Data Science Portfolio

A production-grade, evidence-driven personal portfolio website engineered for **Bhavya Modi** (B.Tech Information Technology student specializing in Data Science & Analytics, Full-Stack Software Engineering, and AI/ML).

Built with **React, TypeScript, Vite, Tailwind CSS, and Lucide React**.

---

## 🚀 Quick Start & Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build & Validation
```bash
npm run build
```

---

## 🌐 Deployment to Vercel / Netlify

### Deploy on Vercel
1. Push your repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your repository (`bhavya277/My-Portfolio`).
4. Framework Preset: **Vite**.
5. Click **"Deploy"**.
